## GitHub Achievement Goals
Pursue achievements organically through genuine collaboration and meaningful work. Never create artificial issues, low-value pull requests, spam, or engagement manipulation. Possible achievements include Quickdraw, Pull Shark, Pair Extraordinaire, Galaxy Brain, and Starstruck. Eligibility and tiers depend on GitHub rules.
