# Security Policy

## Reporting a Vulnerability
Do not disclose exploitable vulnerabilities in public issues.

Contact the repository maintainers privately through GitHub security advisories when private vulnerability reporting is enabled.

Include:
- A description of the vulnerability
- Impact and affected components
- Reproduction steps
- Suggested mitigation if known

Please avoid accessing, modifying, or exposing other peoples data during security research.

## Response
Reports will be triaged, validated, prioritized, and addressed according to severity and maintainer capacity.
